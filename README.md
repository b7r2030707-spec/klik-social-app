# Klik - منصة اجتماعية شاملة 🚀

> تطبيق جوال اجتماعي حديث مع دعم كامل للعربية والذكاء الاصطناعي

## المميزات الرئيسية

✨ **التصميم**
- وضع داكن (Dark Mode) كافتراضي
- ألوان رمادية داكنة وزرقاء
- دعم RTL كامل مع خط Cairo
- شريط تنقل سفلي (Bottom Navigation)

🎬 **الصفحات**
1. **الرئيسية (Shorts)** - فيديوهات قصيرة عمودية
2. **الاستكشاف** - شبكة منشورات مع هاشتاجات
3. **الرسائل** - محادثات ودردشات جماعية
4. **الذكاء الاصطناعي** - توليد صور وفيديوهات
5. **الملف الشخصي** - ملف المستخدم ومنشوراته
6. **القروبات** - قروبات عامة وخاصة

🔐 **المميزات**
- نظام تسجيل دخول وإنشاء حساب
- إعجابات وتعليقات ومشاركات
- دعم الذكاء الاصطناعي (Replicate API)
- قروبات عامة وخاصة
- نظام المتابعين

## التقنيات المستخدمة

- **React 18** - مكتبة UI
- **Next.js 14** - Framework
- **Tailwind CSS** - التصميم
- **shadcn/ui** - مكونات UI
- **Zustand** - إدارة الحالة
- **Framer Motion** - الرسوميات
- **Replicate API** - توليد AI

## البدء السريع

```bash
# تثبيت المتعلقات
npm install

# تشغيل الخادم التطويري
npm run dev

# الدخول إلى التطبيق
# http://localhost:3000
```

## البناء للإنتاج

```bash
npm run build
npm run start
```

## هيكل المشروع

```
src/
├── app/              # صفحات التطبيق
├── components/       # المكونات المشتركة
├── pages/            # API Routes
├── stores/           # إدارة الحالة (Zustand)
├── types/            # أنواع TypeScript
├── styles/           # التصميمات العامة
└── utils/            # دوال مساعدة
```
